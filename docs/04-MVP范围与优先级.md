# 04 - MVP 范围与优先级

> 权威文档：功能范围与验收标准。进度状态一律见 91，本文不维护状态。

## 1. MVP 目标

**一个人 + 一个小团队，把 Linkbase 当 Notion 用**：注册即写、页面树组织、块编辑流畅、多端同步不丢字、能搜索、能贴图、能打标签。实时多人协作是第一个里程碑后的下一站，不在 MVP 内。

## 2. P0（MVP，Phase 0–1 完成）

| # | 功能 | 验收标准 |
|---|------|----------|
| P0-1 | 注册 / 登录 / 登出 | 邮箱+密码；Access Token 15min + Refresh 7d；刷新无感 |
| P0-2 | 零仪式首屏 | 注册后直接进入自动创建的工作空间与《快速开始》页面，光标可立即输入 |
| P0-3 | BlockNote 编辑器（完整形态，05 §2） | 段落/标题(1-6 可折叠)/引用/分割线/无序·有序·待办列表/代码块(语法高亮)/表格(表头·单元格配色·拆分合并)/图片·视频·音频·文件(上传接 blobs)/多栏布局/数学公式(LaTeX)；`/` slash 菜单；块拖拽排序；行内工具栏(加粗/斜体/下划线/删除线/行内码/颜色)；Markdown 快捷输入；**UI 简体中文字典内建** |
| P0-4 | 页面 CRUD 与页面树 | 新建/重命名/删除入回收站/恢复；侧边栏树展示；子页面块建页；树内拖拽换序换父 |
| P0-5 | 内容自动保存（单人多端） | 编辑防抖 800ms 自动 PUT /doc 落库；换设备/浏览器打开同一页面内容一致 |
| P0-6 | 回收站 | 列表、恢复、彻底删除、30 天自动清理任务 |
| P0-7 | 标签 | 增删改、给页面打标签、侧边栏标签聚合视图 |
| P0-8 | 收藏 | 收藏/取消，侧边栏置顶区 |
| P0-9 | 图片附件 | 拖拽/粘贴图片上传（BlobSource 走服务端），块内展示 |
| P0-10 | 搜索 | 按标题 + 正文关键词搜索页面，结果含路径面包屑 |
| P0-11 | ⌘K 命令面板 | 快速跳页、新建页面、搜索三合一 |
| P0-12 | 单机部署 | `docker compose up -d` 一条命令拉起全栈 |
| P0-13 | Database 块基础 | 新建 database、文本/选择/日期/人员等基础列、表格与看板视图切换、看板按选择列分组；行可新建为子页面；**BlockNote 无内建对应物，自研自定义块方案待立项重评估（91 §4）** |
| P0-14 | 国际化基础 | i18next 框架（zh-CN 默认）；**全部 app chrome 文案走 i18n**，禁止硬编码；API 错误按 code 本地化；语言切换（设置 + 登录页）并持久化（13） |

## 5. 非功能验收（P0 期）

| 指标 | 目标 |
|------|------|
| 首屏可交互（已有会话） | < 1.5s（本地网络） |
| 输入延迟 | 感知为零（本地编辑，不等待网络；同步后台进行） |
| 同步可靠性 | 断网继续编辑，恢复后自动补推，无内容丢失（e2e 用例覆盖） |
| API P95（除搜索） | < 200ms |
| 搜索 | < 500ms（万页级数据集） |
| Docker 冷启动 | < 60s 全部健康 |

## 6. 明确不做（MVP）

- 项目/需求实体（已从模型中移除，见 02）；
- 页面级权限、公开分享、访客；
- 离线 PWA 与移动端 App（响应式 Web 够用即可）；
- 多实例水平扩展（单机 docker compose；架构上不留单例假设的死锁——WS 广播如需扩展走 Redis pub/sub，见 09 §7）；
- Figma 集成、Webhook、开放 API；
- 计费与多租户配额。

## 7. 验收方式

每个 P0 项在 90-执行计划 中对应任务与验收用例；e2e 用 Playwright 覆盖 P0-2/4/5/6/10/14 的主路径（沿用现有 e2e 基建）。

## 8. 待细化

- 回收站 30 天自动清理的调度实现（倾向 server 内置定时任务，Phase 1 定）。
- 图片以外附件（PDF 等）是否进 P0——倾向 P1，MVP 仅图片。
