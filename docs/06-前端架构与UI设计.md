# 06 - 前端架构与 UI 设计

> 权威文档：前端技术架构、目录结构、状态管理边界、**UI 设计语言（对标 Notion）**。编辑器接入细节见 05。

## 1. 技术栈

**总策略**：前端全部取**当前最新稳定版**（实施当日 npm latest），`bun install` 锁 `bun.lock`；唯一硬约束是 **BlockSuite 0.22.4（vendored）**——凡与它冲突的依赖降级并登记，**兼容优先于最新**（红线见 §1.1）。

> 实测基线（2026-09-29，registry latest）：React 19.3.0、Vite 8.3.1、TypeScript 7.0.2、Tailwind 4.3.3、react-router 8.4.0、Zod 4.6.5、Vitest 5.0.2。

| 类别 | 选型（参考基线，以实施日 latest 为准） | 关键兼容点 |
|------|------|------|

### 1.1 依赖版本与兼容性红线

> 这些是历史踩坑固化的硬规则；违反任一条都可能导致编辑器不可用或 CRDT 分裂。

1. **Yjs 单实例（最高红线）**：前端直接依赖 `yjs@^13`，BlockSuite 子包内部同为 `^13.6`；用 Bun `overrides` 钉死 `yjs`/`react`/`react-dom` 为单版本。合并前跑 `bun pm ls yjs react react-dom` 确认无重复——双实例会导致 CRDT 分裂。
2. **React 19 + 自定义元素**：`<affine-editor-container>` 用 `useRef` 命令式设置属性（05 §5），复杂对象（doc/specs）不经 React props；**块状态一律不进 React state**（§3）。
3. **Vite 8（rolldown）**：确认 `@vitejs/plugin-react`、`@rolldown/plugin-babel`、`@tailwindcss/vite` 均已适配当前主线；任一插件未适配则整体降到上一稳定主线（兼容优先）。
4. **shadcn/ui（Base UI）生成物两个必做修正**：①生成的 UI 组件 `import { cn } from "cn"` 一律改为 `@/lib/utils`；②`main.tsx` 必须 `import './index.css'`（否则全站无样式）。
5. **Base UI 语法**：自定义触发器用 `render={<Button/>}`，不是 Radix 的 `asChild`；toast 用 `toast.add({ title, type })` 并挂 `<Toaster/>`；表单用 Field/FieldLabel。
6. **react-router 单包**：从 `react-router` 导入（`react-router-dom` 无 7+ 版本）；跨层跳转用绝对路径，相对 `<Link to="..">` 按路由层级解析会出错。
7. **Zod 同版**：`packages/contracts` 统一 Zod 4，`@hono/zod-validator`（后端）与 `@hookform/resolvers`（前端）都需支持该大版本；升级 Zod 必须前后端同批。
8. **Tailwind 4**：不要照抄 shadcn demo 的 `theme(spacing.16)` inline style（v4 下 `spacing.16` 的点被 CSS 注释吞掉，`--sidebar-width` 失效、侧边栏宽度归零）；`SidebarProvider` 用组件默认宽度。
9. **测试分工**：`apps/web` 组件测试用 Vitest（复用 Vite 插件链）；`apps/server` 与共享包用 `bun test`；e2e 统一 Playwright。
10. **i18n 单一来源**：应用文案一律走 13（禁止硬编码）；BlockSuite 无内建 i18n（硬编码英文），编辑器 UI 的本地化按 13 §5 分层处理，不得在组件里内联文案。

## 2. 路由

| 路径 | 页面 | 说明 |
|------|------|------|
| `/login` `/register` | 认证页 | 居中卡片，品牌侧文案 |
| `/` | 重定向 | 有会话 → 最近工作空间的最近页；无 → /login |
| `/:workspaceId` | 工作空间首页 | 空间默认页（第一个顶级页面或新建引导） |
| `/:workspaceId/page/:pageId` | 编辑器页 | 主界面，MVP 唯一复杂页 |
| `/:workspaceId/trash` | 回收站 | 列表 + 恢复/彻底删除 |
| `/:workspaceId/settings/*` | 设置 | 成员 / 标签 / 空间信息（Tab 子路由） |
| `/invite/:token` | 邀请落地 | 登录后自动加入并跳转 |
| `*` | 404 | |

页面切换 **不卸载 DocCollection**（挂在工作空间层），仅切换 editor 的 doc，保证跨页秒开。

语言偏好**不进 URL**（13 §1）：路由不含 locale 前缀，语言是用户偏好而非路由维度，页面链接永远稳定。

## 3. 状态管理边界（红线）

| 状态 | 归属 | 说明 |
|------|------|------|
| 块内容 / 光标 / 选区 / 撤销栈 | **BlockSuite（Y.Doc）** | React 绝不复制、不代理、不缓存块状态 |
| 页面列表 / 树 / 标签 / 成员 | TanStack Query | 服务端状态，缓存键按工作空间隔离 |
| 会话（token、user） | Zustand + localStorage | 见 07 §5 |
| UI 偏好（侧边栏折叠、主题） | Zustand + localStorage | |

红线：任何「把块内容同步进 React 再渲染」的做法都禁止——侧边栏标题等派生信息直接读 BlockSuite doc 的响应式属性或依赖服务端缓存列。

## 4. HTTP 封装与认证流

- `lib/fetch.ts`：统一 baseURL `/api`、注入 Bearer、401 时用 refresh token 换新并**重放原请求一次**（同时并发去重：多个 401 只发一次刷新）；
- 刷新失败 → 清会话 → 跳 /login；
- 响应错误统一类型 `{ error: { code, message, details? } }`（10 §4），按 code 做 toast/表单错误。

## 5. UI 设计语言（对标 Notion）

**总纲：克制、素净、内容至上。** 界面 chrome 退到背景，注意力留给文字；灰阶几乎无色相，交互反馈以轻微的背景变化为主，动效短促（120–200ms）。

### 5.1 主题体系：shadcn/ui 标准变量 + Tailwind 4 映射

采用 **shadcn/ui 的主题系统**：`styles/tokens.css` 定义全部主题变量（shadcn 标准集 + Linkbase 扩展集），Tailwind 4 用 `@theme inline` 映射成工具类。**组件只允许使用语义 token**（`bg-background`、`bg-sidebar`、`text-muted-foreground`…），禁止裸色值——换风格/换主题只改这一个文件。

1. **命名沿用 shadcn 全集**（background / foreground / primary / secondary / muted / accent / destructive / border / input / ring / sidebar 组），任何 shadcn 生态主题可直接替换；
2. 扩展 token 保持克制，且必须同时进 `@theme inline`；
3. 暗色与亮色**同文件成对维护**，`class="dark"` 切换（跟随系统 + 手动覆盖，存 Zustand UI 偏好，06 §3）；
4. **换风格 = 换值不换名**：未来要品牌化、高对比等新风格，只新建一组变量值，全站（含 BlockSuite 桥接，§6）即刻生效。

| token | 值 | 用途 |

| `--radius-sm` | 4px | 输入框、小按钮 |

### 5.5 核心组件形态

- **页面树节点**：28px 高，图标（📄 页/🗂 分组/自定义 emoji）+ 标题，hover 显示 `⋯`；选中态左侧无色条（Notion 用底色不用色条）；拖拽时父节点高亮 2px 内描边；
- **新建页面**：侧边栏底部常驻 `＋ 新页面`（次按钮样式）；树节点 hover 的 `＋` 在对应节点下建子页；
- **slash 菜单 / 块菜单 / 拖拽手柄**：BlockSuite 自带，做主题适配不重写（§6）；
- **⌘K 面板**：居中 640px 浮层，输入即搜（标题+正文），↑↓ 选择，⏎ 打开，`⌘⏎ 新建名为关键词的页面`；无结果时显示「新建页面：xxx」置顶；
- **标签**：圆角胶囊（tag 色板），页面 header 下方展示行内可增删；
- **回收站**：表格列（标题 / 路径 / 删除时间 / 操作），恢复按钮主色文字链；
- **空状态**：新空间首屏 = 《快速开始》模板页（内容引导而非空白）；搜索无结果给「新建」引导；回收站空给一句文案 + 插画位（P1）；
- **加载态**：页面首载骨架 = 灰块占位（标题条 + 三行正文条），禁止整页 spinner。

### 5.6 文案语气

简体中文、第二人称、动词开头：「移到回收站」而非「删除」（可恢复）；危险操作红字 + 二次确认（彻底删除）；错误 toast 一句话 + 可展开详情。

以上语气适用于各语言版本；所有文案经 i18n（13），**中文原文即 `zh-CN` 资源基线**，`en` 由它翻译——写文案时直接写中文 key 值，不要先写英文。

## 6. BlockSuite 主题桥接

BlockSuite 组件是 Lit Web Component，样式变量前缀 `--affine-*`。在 `styles/blocksuite-bridge.css` 中把我们的 token 映射过去（仅列关键项，实施时以 `blocksuite/` 源码 grep `--affine-` 全量对齐）：

```css
affine-editor-container {
  --affine-background-color: var(--background);
  --affine-text-primary-color: var(--foreground);
  --affine-border-color: var(--border);
  --affine-hover-color: var(--muted);
  --affine-primary-color: var(--primary);
  --affine-editor-side-padding: 96px;
  --affine-font-family: var(--font-sans);
}
```

侧边栏/浮层等自有组件全部用 shadcn/ui 改造：只消费语义 token，向 §5 配色收敛。**主题切换对编辑器同样生效**——桥接层只引用语义变量，换主题无需改桥接。

## 7. 性能

- 路由级代码分割：编辑器 chunk（BlockSuite 全家桶）单独切出，首屏（登录页）不加载编辑器代码；
- 页面列表虚拟滚动（P1，页面 > 200 时）；
- 附件图片走服务端缩略参数（P1）；
- 构建产物 size 预算：编辑器 chunk < 2.5MB gz（超了就分析，BlockSuite 按需子路径导入）；
- i18n 资源按命名空间拆分：首屏仅 `common`+`auth`（构建期内联），`workspace`/`editor` 命名空间随对应 chunk 动态加载，登录页不下载全量文案（13 §3）。
